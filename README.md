# Predicting one-year postoperative functional status in contrast-enhancing glioma

[![medRxiv](https://img.shields.io/badge/medRxiv-preprint-b31b1b.svg)](https://www.medrxiv.org/content/10.64898/2026.04.28.26351937v1)
[![Streamlit](https://img.shields.io/badge/Built%20with-Streamlit-FF4B4B?logo=streamlit&logoColor=white)](https://streamlit.io)

This repository contains the code for an open-access, web-based app built to show how the prediction model developed in our project can be used in practice.

## About

The app provides an interactive interface to the model for predicting one-year postoperative functional status in patients with contrast-enhancing glioma.

Other researchers are encouraged to build on this work and extend the model, for example to other outcomes or to different time points, as discussed in our paper.
